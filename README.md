## ¿Qué es este proyecto?

Es un programa sencillo diseñado para ayudar a pequeñas tiendas a llevar el control de su inventario de manera organizada. Permite registrar productos, consultarlos, buscarlos, eliminarlos y conocer el valor total de lo que tienen almacenado.

### Problema que resuelve
Muchos pequeños negocios llevan su inventario en papel o en la memoria, lo que provoca errores, pérdida de información y desorganización. Este programa ofrece una alternativa digital, rápida y gratuita.

---

## ¿Qué aprendí y apliqué en este proyecto?

| Concepto | Cómo lo usé en el programa |
|----------|----------------------------|
| *Variables y tipos de datos* | Uso cadenas de texto, números enteros y decimales para almacenar información de productos |
| *Estructuras de control: if-else* | Verifico si las opciones del menú son correctas y si un producto existe antes de eliminarlo |
| *Ciclos: while y for* | Uso while para mantener el menú activo hasta que el usuario decida salir. Uso for para recorrer y mostrar los productos |
| *Funciones* | Cada acción está en su propia función — el código queda ordenado y se puede reutilizar |
| *Diccionarios* | Almaceno cada producto con su nombre como clave y sus datos como valor |
| *Entrada y salida de datos* | El programa muestra mensajes y recibe información del usuario por teclado |

## ¿Cómo ejecutar el programa?

1. Abre una terminal
2. Escribe: python proyecto_final.py
3. Sigue las instrucciones que aparecen en pantalla

---

## ¿Qué hace cada función?

| Función | Qué hace |
|---------|----------|
| agregar_producto() | Registra un producto nuevo con su precio y cantidad |
| mostrar_inventario() | Muestra todos los productos guardados |
| buscar_producto() | Encuentra un producto por su nombre |
| eliminar_producto() | Borra un producto del sistema |
| calcular_total() | Suma el valor de todo lo que hay en inventario |
| main() | Muestra el menú principal y conecta todo |
